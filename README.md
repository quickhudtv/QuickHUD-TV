# QuickHUD-TV

![QuickHUD TV Banner](tv_banner.png)

Smart overlay menu and sleep timer for Android TV on top of any video, allowing instant access to apps without leaving your content.

*   **Smart Overlay & Sleep Timer**
*   **Customizable Quick Slots**
*   **Button Remapping (Netflix, YouTube, etc.)**
*   **TV-Optimized Design**
